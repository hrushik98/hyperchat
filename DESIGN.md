# Harper chat interface

## Reference

Match the user-supplied chat screenshot: a near-white canvas, right-aligned mint user bubbles, unboxed assistant responses, small muted action icons, and a bottom pill composer. A person reading and typing in this light conversation surface should see the messages before the controls.

## Visual System

- Restrained palette: neutral text and surfaces, mint prompts, a green send action.
- System sans-serif typography; conversation text at 18px on desktop and 16px on mobile.
- Centered conversation and composer with a maximum width of 846px.
- User bubbles have generous horizontal padding and fully rounded corners.
- Assistant replies use the full conversation width without avatars or bylines.
- History is available in a collapsible drawer on every viewport.
- The composer has a plus action for a new conversation, a growing textarea, model and thinking controls, and a circular send/stop action.
- Display a concise accuracy note directly above the composer.
- Keep Markdown, code blocks, thinking details, loading, and error states readable.
